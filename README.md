# Проверка статистических гипотез и анализ A/B-теста

## О проекте

Итоговый проект третьего модуля курса «Аналитик данных» Яндекс Практикума состоит из двух самостоятельных исследований:

1. **Яндекс Книги** — проверка гипотезы о различиях в пользовательской активности между Москвой и Санкт-Петербургом.
2. **BitMotion Kit** — оценка результатов A/B-теста нового интерфейса интернет-магазина.

**Цель проекта** — применить методы статистического анализа для проверки гипотез, оценки изменений пользовательского поведения и подготовки рекомендаций на основе данных.

## Часть 1. Яндекс Книги — проверка статистической гипотезы

### Задача

Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.

### Ход исследования

- Загружены и изучены данные об активности пользователей двух городов.
- Проведена проверка пропусков и дубликатов.
- Исследованы распределения времени чтения и прослушивания.
- Сформированы независимые выборки пользователей.
- Для проверки односторонней гипотезы применён критерий Манна — Уитни.
- Подготовлена аналитическая записка с интерпретацией результатов.

### Результат

При уровне статистической значимости 5% получено **p-value = 0,45**.

Статистически значимых оснований считать, что пользователи Санкт-Петербурга проводят в сервисе больше времени, чем пользователи Москвы, не обнаружено.

## Часть 2. BitMotion Kit — анализ A/B-теста

### Задача

Оценить корректность проведения A/B-теста нового интерфейса интернет-магазина и проверить, увеличилась ли конверсия пользователей в покупку.

Ожидаемый эффект эксперимента — увеличение конверсии не менее чем на **3 процентных пункта**.

### Ход исследования

- Изучены данные о событиях пользователей и распределении участников по экспериментальным группам.
- Проверены пропуски и дубликаты, выполнена очистка данных.
- Выявлены и исключены пользователи, одновременно участвовавшие в конкурирующих экспериментах.
- Ограничен горизонт анализа первыми семью днями после регистрации.
- Оценена достаточность размера выборки.
- Рассчитана конверсия в покупку для контрольной и тестовой групп.
- Проведён односторонний z-тест пропорций.
- Подготовлены выводы и рекомендации по дальнейшему развитию продукта.

### Результаты

После очистки данных в эксперименте осталось 4 952 пользователя в группе A и 5 011 пользователей в группе B.

| Показатель | Группа A | Группа B |
|---|---:|---:|
| Количество пользователей | 4 952 | 5 011 |
| Конверсия в покупку | 27,8% | 29,5% |

**Результат статистического теста: p-value = 0,03** при уровне значимости 0,05.

Различие между группами статистически значимо: конверсия в тестовой группе выше.

Однако фактический прирост составил около **1,7 процентного пункта**, что ниже запланированного эффекта в 3 процентных пункта.

## Итог

В рамках проекта проведены два статистических исследования с разными результатами:

- Для Яндекс Книг гипотеза о более высокой активности пользователей Санкт-Петербурга не получила статистического подтверждения.

Проект демонстрирует применение статистических методов для оценки пользовательского поведения, проверки гипотез и принятия решений на основе данных.
